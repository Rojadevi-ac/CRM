# 💼 Customer Relationship Management System

A web-based **Customer Relationship Management (CRM) System** developed as a full-stack project to help organizations manage leads, customers, users, business activities, reports, and company information in one centralized application.

The system provides a user-friendly dashboard with role-based access, customer and lead management, reporting features, and customizable user preferences.

---

## 📌 Project Description

The **Customer Relationship Management System** is designed to simplify and organize customer-related business activities.

The application allows users to manage customer information, track leads, monitor business activities, generate reports, and manage users through a centralized platform.

The project consists of a **React frontend**, **Flask backend**, and **MySQL database**.

---

## 🎯 Objectives

* To develop a centralized platform for managing customers and leads.
* To maintain customer and business information efficiently.
* To provide secure user authentication and authorization.
* To manage users based on their roles and permissions.
* To provide dashboard-based business analytics.
* To generate and export business reports.
* To provide company and profile management.
* To provide customizable user interface preferences.

## ⚙️ Installation

### 📥 Prerequisites

Before running the project, make sure the following are installed:

* 🐍 Python
* 📦 Node.js and npm
* 🐬 MySQL
* 💻 Git

### 🐍 Backend Setup

1. Open the project folder.
2. Navigate to the backend folder.
3. Create and activate a Python virtual environment.
4. Install the required Python packages from `requirements.txt`.
5. Configure the MySQL database and environment variables.
6. Start the Flask server.

### 🗄️ Database Setup

1. Install and start MySQL.
2. Create the required database.
3. Configure the database connection details in the backend environment file.
4. Make sure the backend can successfully connect to MySQL.

### ⚛️ Frontend Setup

1. Navigate to the frontend folder.
2. Install the required npm packages.
3. Configure the backend API URL in the frontend environment file.
4. Start the Vite development server.
